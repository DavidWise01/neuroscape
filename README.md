# Neuroscape / Ether Arena

Visual-first standalone browser training sandbox. Open index.html locally or via GitHub Pages. Original embedded SVG artwork; no remote assets. Inspired by [Neuroscape Local v0.2.1](https://github.com/nothingalike/deckscape-app/releases/tag/v0.2.1). Independent simplified rules and training cards, not an official port. Upstream code and official artwork are not redistributed.

Click affordable cards to deploy, then ready units to attack. End turn to let the bot respond. Reduce opposing health to zero. Deck lab supports editing and JSON export. Browser storage preserves the match and deck.
